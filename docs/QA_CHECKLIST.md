# Phase 1 QA Checklist

## Desktop
- [ ] Navigation remains visible and active underline works
- [ ] Hero typography is readable and no text clips
- [ ] Counters animate once from zero
- [ ] Spotlight follows pointer inside cards
- [ ] Tilt remains subtle
- [ ] Aurora haze does not obscure text
- [ ] Buttons remain stable and readable

## Mobile
- [ ] No horizontal scroll
- [ ] Navigation remains usable
- [ ] Tap highlights cards
- [ ] Cards stack correctly
- [ ] Reduced motion is respected

## Approval gate
Do not begin Phase 2 until colour, spacing, typography, cards, buttons, motion, and mobile behaviour are approved.
