## Upload steps
1. Extract this ZIP.
2. Copy every file and folder into the root of `kpadm3.github.io2`.
3. Choose **Replace files in the destination**.
4. Test locally:
   `python -m http.server 8000`
5. Open:
   `http://localhost:8000`
6. Hard refresh:
   `Ctrl + Shift + R`
7. Also test:
   `http://localhost:8000/solutions/enterprise-product-configuration.html`
8. Commit only after both pages look correct.
